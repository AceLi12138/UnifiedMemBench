# Stagewise PT Data

This directory is the expected location for stagewise pretraining JSONL files:

```text
stage_01_pt.jsonl
stage_02_pt.jsonl
...
stage_10_pt.jsonl
```

These files are generated by:

```bash
python dialogue_training/prepare_dialogue_project.py \
  --dataset_path dialogue_gen_api/output/final/clean_v8_budget_direct/UMB_dialogue_benchmark.json \
  --output_dir dialogue_training/project_entity_split_sw_natural_header_qa_upweight24 \
  --project_mode entity_split \
  --num_stages 10 \
  --chunking_mode sliding_window \
  --sliding_window_overlap_tokens 1024 \
  --pt_header_style natural \
  --qa_sampling_mode role_balanced_upweight \
  --qa_max_samples_per_character 24
```

The PT files are intentionally excluded from git because they are large and two
of them exceed GitHub's 100MB single-file limit in the current build:

- `stage_06_pt.jsonl`
- `stage_09_pt.jsonl`

Use the script above to regenerate them from the clean long-dialogue benchmark,
or download the prepared PT / SFT / unseen evaluation files from:

https://huggingface.co/datasets/Ace1213812/UnifiedMemBench-ParametricMemory

The public parametric-memory dataset includes the stagewise PT files,
QA-SFT files, and held-out / unseen evaluation files. The seen split is not
distributed in the current public dataset package.
